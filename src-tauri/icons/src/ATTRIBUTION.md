# Icon sources

`codecarbon-logo.svg`, `app-icon.svg` (the project favicon) and the molecule mark in
`tray-mark.svg` come from the CodeCarbon repository
<https://github.com/mlco2/codecarbon> (`docs/images/`), MIT licence.

Tray icons are rendered from `tray-mark.svg`: active = brand lime `#BFFB4F`,
idle = grey `#9E9E9E`. On macOS they are template images (alpha only), so the
idle state uses 45 % opacity instead of a colour.
